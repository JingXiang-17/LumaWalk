# Frontend guide

The active Flutter project is `lunawalk_frontend/`. The old `frontend/` path is
kept only for this compatibility note; do not run `flutter create` there.

From PowerShell:

```powershell
cd "c:\Documents\docs\Desktop\LumaWalk\LumaWalk\lunawalk_frontend"
flutter pub get
flutter devices
flutter run -d chrome
```

Start the FastAPI backend separately from `backend/`. The frontend uses
`http://localhost:8000` on web, desktop, and iOS simulator targets. Android
emulators reach the host backend through `http://10.0.2.2:8000`.

See `lunawalk_frontend/README.md` for the user workflow and the root
`README.md` for the complete repository setup.
